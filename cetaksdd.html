BAB IV: PEMODELAN UML 3 — CLASS DIAGRAM BERORIENTASI OBJEK & SOLID

4.1 Penerapan Prinsip SOLID dalam Desain Perangkat Lunak

1. Single Responsibility Principle (SRP): Setiap Controller dan Service memiliki satu tugas spesifik. LoanController mengurus siklus pinjaman, WhatsAppService menangani pengiriman gateway API Fonnte, dan PustakaAIService menangani retrieval konteks chatbot.
2. Open/Closed Principle (OCP): Integrasi gateway notifikasi dirancang dengan interface sehingga penambahan provider baru tidak memodifikasi controller.
3. Dependency Inversion Principle (DIP): Controller bergantung pada abstraksi Service, bukan implementasi langsung tingkat rendah.
